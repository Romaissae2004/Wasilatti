# Wasilatti

Wasilatti — A delivery platform connecting clients, merchants, and delivery drivers. Built with Spring Boot, React, PostgreSQL, and JWT authentication.

## 🚀 Features

- User authentication and authorization
- Client management
- Merchant management
- Product and order management
- Shopping cart
- Delivery assignment
- Order tracking
- GPS-based checkout
- JWT authentication
- Google OAuth2

## 🛠️ Technologies

### Backend
- Java
- Spring Boot
- Spring Security
- PostgreSQL
- JWT
- REST API

### Frontend
- React
- Tailwind CSS
- Axios

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Romaissae2004/Wasilatti.git
```

### 2. Backend Setup

Go to the backend directory:

```bash
cd backend
```

Configure your PostgreSQL database and update the database credentials in the backend configuration.

Then run the Spring Boot application from your IDE or using Maven:

```bash
./mvnw spring-boot:run
```

### 3. Frontend Setup

Open a new terminal and go to the frontend directory:

```bash
cd frontend
```

Install the required dependencies:

```bash
npm install
```

Start the React application:

```bash
npm run dev
```

### 4. Database

Wasilatti uses PostgreSQL as its database.

Create a PostgreSQL database and configure the database connection in the backend configuration before starting the application.
